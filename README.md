# etiquetagem-wpp-dist

Repositório público de apoio à extensão **Etiquetagem rápida WhatsApp Web**.

Hoje tem **um único propósito**: hospedar a **política de privacidade** da extensão
via **GitHub Pages** — link exigido na ficha da Chrome Web Store.

- 📄 Política de privacidade: <https://bg-tech-team.github.io/etiquetagem-wpp-dist/privacy.html>

A **extensão** é distribuída pela **Chrome Web Store** (visibilidade "não listada");
o **código-fonte** fica em repositório privado.

> **Histórico:** este repo já serviu a uma distribuição self-hosted (`updates.xml` +
> `.crx` + force-install via política do navegador). Essa abordagem foi abandonada
> porque navegadores Chromium bloqueiam force-install de extensões fora da loja em
> máquinas não gerenciadas por empresa. Esses arquivos foram removidos; a distribuição
> passou a ser pela Chrome Web Store.
