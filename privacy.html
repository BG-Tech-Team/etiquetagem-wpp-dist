Política de Privacidade

Extensão Etiquetagem rápida WhatsApp Web — última atualização: 22/06/2026

Esta extensão é uma ferramenta interna de uso profissional. Ela permite aplicar etiquetas no WhatsApp Web por atalho de teclado e sincronizar o STATUS correspondente no sistema Conecta (projeto conecta-ganem).

Quais dados são tratados

  • E-mail e senha de acesso ao Conecta: informados pelo usuário na tela de login da extensão, usados para autenticar no serviço de autenticação do Firebase (Google). A senha é enviada diretamente ao Firebase e não é armazenada pela extensão.
  • Token de sessão: após o login, um token de autenticação é guardado localmente no seu navegador (chrome.storage.local) apenas para manter a sessão ativa.
  • Código do contato e STATUS: ao etiquetar uma conversa, o código do contato e o STATUS escolhido são enviados ao backend do Conecta para gravar a atualização.

Como os dados são usados

Exclusivamente para autenticar o usuário e gravar o STATUS do contato no Conecta. Os dados não são vendidos, não são compartilhados com terceiros e não são usados para qualquer finalidade não relacionada ao funcionamento descrito.

Onde os dados ficam

O token de sessão fica apenas no seu navegador. Os dados de contato/STATUS são processados pela infraestrutura do Conecta (Google Firebase / Cloud Functions), com acesso restrito por autenticação e permissão.
